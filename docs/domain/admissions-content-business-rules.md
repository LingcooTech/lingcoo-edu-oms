# 招生转化与内容营销业务规则

## 一、核心定位

招生模块负责回答“谁有意向、沟通到了哪一步、是否体验过、是否转成学员”；课时账本负责回答“机构向学员发放了什么课时、发生了什么消费”。两者通过明确的转化动作衔接，但不共享隐式扣课逻辑。

内容是可发布、可追溯的营销资产。内容来源、线索来源和课时来源分别记录，不能因为页面访问或试听签到而推断出课时事实。

## 二、线索状态

| 状态       | 含义                             | 允许的下一步                             |
| ---------- | -------------------------------- | ---------------------------------------- |
| 新线索     | 已收集联系方式，尚未完成有效沟通 | 联系、确认需求、失效                     |
| 已联系     | 已完成至少一次有效沟通           | 确认需求、持续培育、预约试听、失效       |
| 已确认需求 | 已知道基本需求和适配方向         | 预约试听、持续培育、失效                 |
| 已预约试听 | 已存在有效试听报名               | 签到后进入已参加试听，取消后重新跟进     |
| 已参加试听 | 已完成体验交付                   | 转化、持续培育、失效                     |
| 持续培育   | 当前不成交但仍值得保留           | 再次联系、预约试听、转化、失效           |
| 已转化     | 已生成学员档案                   | 进入学员、课时和教务流程                 |
| 已失效     | 当前不再跟进                     | 如重新产生需求，应新建线索或明确恢复规则 |

状态是过程摘要，完整事实以跟进记录、试听报名记录和审计日志为准。

## 三、试听规则

1. 场次必须属于一个经营机构；校区、课程、教师是可选交付上下文。
2. 起止时间必须有效，结束时间晚于开始时间。
3. 报名数不能超过人数上限。
4. 同一线索与同一场次最多一条报名事实记录。
5. 取消后重新预约，应复用原报名关系并恢复为已预约，同时只增加一次有效报名数。
6. 签到必须基于已预约记录；重复签到返回原事实，不重复写入签到时间。
7. 试听签到不扣通用课时。若未来经营上需要试听扣课，必须另设明确的课时消费规则和课时流水事件。

## 四、转化规则

- 线索转化必须明确选择所属机构，因为机构是课时服务和课时包的提供方。
- 转化只负责生成或衔接学员档案，不自动发放课时、不自动安排课程、不自动绑定校区和班级。
- 学员建档后，运营人员再通过课时账本发放该机构的通用课时包。
- 已转化线索不能再次生成新的学员档案；异常情况走人工核对和审计修复。

## 五、内容规则

- 手工内容和 Notion 内容使用同一内容模型。
- 导入保存快照，源页面 ID/URL 用于回溯，不作为每次展示时的实时依赖。
- 默认导入为草稿；只有明确发布后才出现在公开内容 API。
- 草稿和已归档内容不能通过公开接口读取。
- 内容管理不承载渠道、活动和支付逻辑。
