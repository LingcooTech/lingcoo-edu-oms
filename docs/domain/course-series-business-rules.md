# 课程系列业务规则

**文档状态：** 已实施
**定位：** 教学资源目录中的可选分类

课程系列用于把机构的课程档案按产品线、年龄段或教学主题分组，保留旧系统已经使用的名称、编码/slug、说明、排序和启停状态。

核心边界：

- 系列归属机构，同一机构内名称、编码和 slug 分别保持唯一；
- 一门课程可以不属于任何系列，也可以关联一个系列；
- 课程只能关联同一机构的系列；
- 停用系列不改写或停用已关联课程；
- 仍被课程引用的系列不能删除，应先解除关联或改为停用；
- 系列只影响目录组织和展示，不限制课时包、订单、课时账户、课次或签到消课；
- 课程和系列后续变化不改写历史订单、课时流水或教学交付事实。

因此，课程系列是供给侧资源的分类信息，不是课时权益的归属或消费条件。
