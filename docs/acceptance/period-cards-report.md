# 周期卡第一纵向切片验收报告

日期：2026-09-12  
结论：商品、人工发放、课次使用和冲正闭环通过；未执行旧数据迁移，订单购买将在下一纵向切片接入。

## 已验收范围

- 机构范围的周期卡商品与不可变版本；
- 限次卡和不限次卡；
- 日、周、月有效期及 UTC 月末夹取；
- 发放即生效和首次使用激活；
- 学员权益的待激活、有效、已用尽、已过期、已撤销状态；
- 使用数量投影、有效使用记录、冲正记录和并发约束；
- 课次点名后显式选择普通课时或周期卡；
- 周期卡消课和原路冲正不生成普通课时流水；
- 普通课时原消课与冲正流程保持可用；
- 后台周期卡商品、学员权益、使用记录三个页面全部使用 Modal 操作。

## 验证结果

- Drizzle 迁移在隔离预览 PostgreSQL 执行成功；既有普通消课记录已回填为 `lesson_units`。
- 周期卡领域测试：4/4 通过。
- Server 测试：80 通过，80 个数据库条件测试按默认配置跳过。
- Admin 测试：7/7 通过。
- 全工作区 TypeScript、ESLint、模块边界和 Prettier 检查通过。
- Playwright 周期卡真实数据库用例通过：首次激活、重复来源阻断、冲正、真实课次周期卡消课与冲正、后台页面。
- Playwright 原普通课时课次用例单独回归通过。

## 验收中发现并修正的问题

1. 生成迁移中的复合外键早于唯一索引创建；已调整 DDL 顺序。
2. 新增消费来源约束前，既有普通消费缺少来源；已在迁移中显式回填。
3. Drizzle 包装后的唯一冲突未映射为领域错误；已递归识别底层数据库错误并返回 409。
4. 批量候选名单空数组引用不稳定导致 React 无限更新；已稳定引用并避免无变化状态写入。
