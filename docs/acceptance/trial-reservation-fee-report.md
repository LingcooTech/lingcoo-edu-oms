# 试听占位费纵向闭环验收报告

日期：2026-09-12  
结论：OMS 端免费预约与收费占位支付闭环通过；未迁移旧数据，原小程序界面接入待完成。

## 已完成范围

- 试听场次配置占位费、支付保留分钟数和退款截止小时数；
- 免费场次提交后直接确认，不创建支付交易；
- 收费场次先占用容量并进入待支付，支付成功事实到达后确认预约；
- 待支付和已确认预约均占用容量，失败、关闭或超时只释放一次；
- 订单号、收据号、参与人、场次、金额、退款截止时间均形成不可变预约快照；
- 同一身份、场次、同名学员的有效预约防重，创建接口支持幂等重放；
- 支付回调校验交易身份、金额和币种，重复回调不重复确认名额；
- 延迟回调只在仍有容量时恢复名额，不能造成超卖；
- 支付成功只更新招生线索和试听预约，不创建正式学员、课时账户或教学权益；
- 后台收费场次不能绕过支付直接预约，报名名单展示参与人、预约状态、支付状态、订单和收据；
- 通用支付退款入口被领域门禁阻止，等待统一取消退款用例。

## 数据库与兼容性

迁移 `0035_complex_blink.sql` 已在预览 PostgreSQL 成功执行。既有试听报名先从试听场次和招生线索回填机构、场次及参与人快照，再设置非空约束；原免费试听数据保持 `amount_minor = 0`、`payment_status = not_required`。

数据库同时约束状态、金额、币种、支付字段形态、签到时间、版本号以及有效预约唯一性。
