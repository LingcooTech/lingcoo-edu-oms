# 订单退款与权益回收验收报告

验收日期：2026-09-13

## 验收结论

本阶段实现通过。后台订单页已经支持从已完成订单发起全额退款，并把订单、资金退款与原订单权益串成一条受控流程。

## 已验证场景

1. 创建学员和家长绑定；
2. 创建 5 课时商品并补录现金线下订单；
3. 确认订单完成后，学员账户增加 5 课时；
4. 在后台订单列表填写原因并确认线下退款；
5. 订单状态变为“已退款”；
6. 学员账户余额由 5 变为 0；
7. 生成 5 课时的 `grant_reversal` 借方流水；
8. 原订单课时批次状态变为 `reversed`，剩余课时为 0；
9. 创建周期卡订单并先产生 1 次使用记录；
10. 系统拒绝自动退款，返回 `PERIOD_CARD_ENTITLEMENT_ALREADY_USED`，订单恢复并保持“已完成”；
11. 冲正周期卡使用记录后重新退款成功；
12. 周期卡权益变为 `revoked`，使用数量保持 0；
13. 已退款订单不再显示退款操作；
14. 页面运行期间无浏览器脚本错误。
