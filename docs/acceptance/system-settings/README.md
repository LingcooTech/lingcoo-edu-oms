# 系统设置第一阶段验收记录

验收日期：2026-09-09

## 本阶段范围

- 系统设置菜单：品牌设置、接口配置、素材库；
- 品牌设置：四类品牌素材、五个颜色 Token、字体、圆角和登录文案；
- 微信小程序设置：AppID、AppSecret、版本状态和订阅消息模板；
- 七牛云 Kodo：复用 S3-compatible Provider；
- SMTP：沿用统一 Settings、连接测试和邮件任务底座；
- 微信支付：APIv3 配置、请求签名、响应验签和连接测试底座；
- Notion：连接配置、连接测试、页面读取和 Block 分页读取底座。

微信支付业务下单、支付回调、退款与订单业务事实，以及 Notion 内容记录和导入发布流程，不属于本阶段系统设置范围。

## 架构核查

- 敏感配置只在服务端读取，经统一 Settings 加密保存且不通过管理 API 回显；
- 新增适配器通过连接测试注册表接入，不直接访问其他业务模块的 Repository；
- 当前没有为配置展示增加临时 HTTP 接口，避免出现绕过统一 Contract 的 API；
- 接口配置按 Provider 页签展示，字段使用响应式双列卡片，连接测试位于所属 Provider 内；
- 七牛云不复制存储业务逻辑，只使用已有 S3 Provider；
- 微信支付没有提前塞入现有支付意图流程，待订单与收款模块明确 OpenID、回调和幂等边界后接入。

## 验收限制

仓库未保存真实七牛、微信和 Notion 凭据，因此自动化测试验证的是配置、签名、验签、请求构造和错误边界；上线前还需使用部署环境中的真实凭据分别执行一次连接测试。
