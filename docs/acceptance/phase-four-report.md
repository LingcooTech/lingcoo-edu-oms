# 第四阶段管理端验收报告

日期：2026-09-08

## 本次交付

- 机构独立课次：创建、编辑、打开、完成、取消。
- 课次名单：仅允许加入当前机构的有效学员，并保存姓名快照。
- 点名：待点名、到课、迟到、请假、缺勤，与消费状态分离。
- 消课：仅到课或迟到可扣课；按明确正整数课时消费当前机构账户。
- 纠错：撤销后按原消费分摊恢复原批次，可使用新操作号按新数量重新消费。
- 一致性：课次、名单、账户和批次并发控制；幂等、审计、Outbox、数据库检查约束。
- 机构隔离：复合外键同时约束“课次＋机构”和“学员＋机构”，脚本或后续模块也不能写入跨机构名单。
- 管理后台：课次管理和签到消课两个菜单入口，新增与编辑均使用 Modal，支持移动端。
